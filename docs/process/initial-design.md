# 初始设计记录

## 要解决的问题

论文阅读、实验配置、运行结果和结论容易分散在脚本和临时笔记中，难以复盘。项目需要一个离线可运行的最小闭环，把研究假设转成可重复执行的实验任务。

## 现状与取舍

MVP 选择纯 Python 标准库和合成二分类数据，减少环境依赖，让使用者可以在无网络条件下运行。Adam 论文用于验证论文机制能否被准确映射到代码；SGD 作为基线用于比较。

## 最终设计

- `examples/*.json`：研究假设、数据、随机种子和方案配置。
- `autoresearch/dataset.py`：确定性合成数据。
- `autoresearch/model.py`：模型和优化器机制。
- `autoresearch/runner.py`：多方案运行、指标汇总和报告生成。
- `tests/`：配置校验和确定性运行验证。

## 验收方式

在干净 Python 环境执行 README 中的命令，确认配置校验通过、实验报告生成、测试通过，并检查相同配置和随机种子产生相同结果。
