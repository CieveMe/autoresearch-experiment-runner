# 项目证明材料清单

提交时可按审核方要求选择以下材料：

- GitHub 私有仓库链接，并授予只读权限。
- README、架构设计和论文复现说明。
- 实验配置、结构化结果、Markdown 报告和测试输出。
- GitHub commit history、Issue/PR 和 milestone 页面截图。
- 真实开发过程中的设计记录、调试记录和验收记录，提交前脱敏。
- Dockerfile、运行脚本和离线复现命令。
- 后续 TODO 及当前版本限制说明。

截图只作为辅助证据，不能替代代码、真实 Git 历史和可复现实验。不要上传密钥、令牌、证书、个人隐私、客户数据或未授权的内部资料。
