# Adam 复现结果

实验配置：随机种子 `7`，训练集 `600` 条，测试集 `200` 条，固定 80 个训练轮次。

| 方案 | 测试损失 | 测试准确率 |
|---|---:|---:|
| Adam 复现 | 0.20216034 | 94.00% |
| SGD 对照（较高学习率） | 0.28128893 | 94.50% |
| Adam + 正则 | 0.31407811 | 93.50% |
| SGD baseline | 0.38416828 | 93.50% |

结论：在这组小型可控数据上，Adam 的测试损失最低，说明概率输出的整体拟合更好；较高学习率 SGD 的分类准确率略高。这个结果只用于展示复现流程，不外推为论文的完整结论。
