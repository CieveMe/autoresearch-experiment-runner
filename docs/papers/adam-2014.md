# Adam 论文复现记录

## 论文信息

- 论文：*Adam: A Method for Stochastic Optimization*
- 作者：Diederik P. Kingma、Jimmy Ba
- 年份：2014
- 标识：arXiv:1412.6980

## 从论文到工程任务

研究问题：在同一个固定数据集和随机种子下，Adam 的自适应一阶/二阶矩估计与偏差修正是否比固定学习率 SGD 更快收敛？

工程任务：

1. 用固定随机种子生成二分类数据集，并固定训练/测试切分。
2. 以固定学习率 SGD 作为 baseline。
3. 按论文中的 `m_t`、`v_t`、偏差修正 `m_hat_t` / `v_hat_t` 实现 Adam。
4. 记录测试准确率、测试损失、训练轮数和耗时。
5. 使用相同数据和预算比较 baseline、Adam 以及带正则的 Adam。

## 实现映射

`autoresearch/model.py` 的 `optimizer=adam` 分支对应论文的矩估计和偏差修正；`examples/classification.json` 固定了实验假设、随机种子、基线和对照变量；`runner.py` 负责运行、排序和生成报告。

## 复现边界

该 MVP 验证的是优化器机制在小型可控任务上的工程复现，不声称复现论文全部实验或原始数据集。后续接入真实论文时，应替换数据集和模型，并记录依赖版本、硬件、checkpoint 和完整实验预算。
